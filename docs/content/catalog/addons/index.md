# Overview

**Add-ons** are optional extras clients can add when booking a service - for example extra edited photos, a printed album, or travel time. Each add-on has a name, short description, duration, and price. You can also attach [Fields](/docs/catalog/fields) and set **Member overrides** for individual staff.

Open **Appointments → Catalog → Add-ons** in the side menu.

An add-on lives in the catalog once. You attach it on the [services](/docs/catalog/services) that should offer it. Changing the add-on updates it everywhere it is used.

## What you can do here

- [Listing add-ons](./addons/listing-addons) - search, open a row, clone, or delete one or more at once.
- [Creating a new add-on](./addons/creating-a-new-addon) - add an add-on with details, fields, and member overrides.
- [Updating an existing add-on](./addons/updating-an-existing-addon) - change name, description, duration, price, fields, or overrides.
- [Deleting an add-on](./addons/deleting-an-addon) - remove an add-on from the catalog and from services that used it.

### Good to know

Creating an add-on does not put it on a booking yet. Attach it on the service you want clients to see it for.
