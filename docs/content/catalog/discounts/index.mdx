# Overview

<PlanRequirement plan="Solo" />

**Discounts** reduce the price of services, add-ons, or packages when a client uses a promo code. Each discount has a type (**Percentage** or **Fixed amount**), a value, optional date windows, usage limits, and optional limits to specific catalog items.

Open **Appointments → Catalog → Discounts** in the side menu.

## What you can do here

- [Listing discounts](./discounts/listing-discounts) - search, filter, clone, update, or delete discounts.
- [Creating a new discount](./discounts/creating-a-new-discount) - set type, value, dates, promo codes, and limits.
- [Updating an existing discount](./discounts/updating-an-existing-discount) - change status, codes, dates, or limits.
- [Deleting a discount](./discounts/deleting-a-discount) - remove a discount from the catalog.

### Good to know

Past appointments keep any discount they already used. Changing or deleting a discount does not rewrite those bookings.
