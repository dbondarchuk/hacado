# Deleting a discount

Delete a discount when you no longer offer that promotion. Deleting removes it from Catalog. Past appointments keep any discount details they already stored.

## Delete one discount

1. Open **Appointments → Catalog → Discounts**.
2. Open the row menu on the discount.
3. Click **Delete**.

![Row menu with Delete](/img/catalog/discounts/row-menu.png)

![Delete confirmation dialog](/img/catalog/discounts/delete-confirm.png)

4. Read the confirm dialog. It warns that the action cannot be undone.
5. Confirm to delete, or cancel to keep the discount.

## Delete several discounts

1. Check the discounts to remove, or use **Select all**.
2. Click **Delete selected**.
3. Confirm in the dialog.
4. Click **Delete selected** in the dialog, or **Cancel** to stop.

## What happens next

- The discount leaves the **Discounts** list.
- Clients can no longer apply its promo codes.
- You cannot undo a delete. Create the discount again if you still need a similar promotion - see [Creating a new discount](./creating-a-new-discount).

### Good to know

If you only need to pause a promotion, set **Status** to **Disabled** instead of deleting - see [Updating an existing discount](./updating-an-existing-discount).
