# Field types

Every field has a **Type**. The type controls what clients enter on the booking form. You pick it when [creating](./creating-a-new-field) or [updating](./updating-an-existing-field) a field.

Open **Type** on the field form to choose one of the eight options.

![Type picker with all field types](/img/catalog/fields/type-picker.png)

## Name

**Name** asks for a person's name. Use it when you need the client's name as its own field on a service or add-on.

## Email

**Email** asks for an email address and checks that the value looks like an email.

## Phone

**Phone** asks for a phone number in a phone-friendly input.

## One line

**One line** is a short single-line text answer - for example a referral code or a short preference.

New fields start as **One line** until you change the type.

## Multi line

**Multi line** is a longer text box for notes, special requests, or anything that needs more than one line.

## Checkbox

**Checkbox** is a yes/no choice. Use it for agreements such as accepting a studio policy.

## Select

**Select** shows a list of choices. Clients pick one option.

When **Type** is **Select**, an **Options** section appears. You must add at least one option before you can save.

![Select field Options list with reorder controls](/img/catalog/fields/select-options.png)

1. Click **Add a new item** to add an option.
2. Enter the **Option** text clients will see.
3. Drag with **Move option** to change the order.
4. Remove an option only when you no longer want it on the list. Confirm if Hacado asks.

### Good to know

Option labels must be unique within that field.

## File

**File** lets clients upload a file during booking - for example inspiration images or a document.

When **Type** is **File**, a **File settings** card appears.

![File settings with max size and accepted files](/img/catalog/fields/file-settings.png)

### Max file size

1. Enter **Max file size (MB)** if you want a limit.
2. Leave it blank if you do not need a custom limit.

The value must be between 1 and 100 if you set one.

### Accepted files

1. Click the plus control on **Accepted files**.
2. Choose a group: **Images**, **Videos**, **Audios**, or **Documents**.
3. Click **Add option** to put that group on the list.
4. Repeat for every group you want to allow.
5. Remove a tag from the list if that group should not be accepted.

![Accepted files picker with Images, Videos, Audios, and Documents](/img/catalog/fields/file-accept-picker.png)

### Good to know

If you leave **Accepted files** empty, Hacado does not restrict the upload to those groups. Set the list when you only want certain kinds of files.

## Required for every type

The **Required** switch works the same for all types:

- **On** - clients must complete the field before they can finish booking.
- **Off** - clients can skip it.

![Required switch on a field form](/img/catalog/fields/required-switch.png)
