# Updating an existing field

Change a field when the question, type, or options no longer match how you book. Edits apply everywhere that field is already attached.

## Open the field

1. Open **Appointments → Catalog → Fields**.
2. Click the field name, or open the row menu and choose **Update**.

The edit form shows the current **Details**, **Required** setting, and any type-specific sections.

![Edit field form with details and required switch](/img/catalog/fields/update-form.png)

## Change details

1. Update **Name** if you need a different internal ID. It must stay unique and use only letters, digits, and underscores.
2. Update **Label** to change what clients read on the booking form.
3. Change **Type** if the answer should use a different input. See [Field types](./field-types).
4. Edit **Description** when clients need more help under the label.
5. Turn **Required** on or off.

![Required switch on or off](/img/catalog/fields/required-switch.png)

## Type-specific settings

- **Select** - edit, reorder, add, or remove choices under **Options**.

![Select options on the edit form](/img/catalog/fields/select-options.png)

- **File** - adjust **Max file size (MB)** and **Accepted files** under **File settings**.

![File settings on the edit form](/img/catalog/fields/file-settings.png)

If you switch away from **Select** or **File**, those extra sections no longer apply to the new type.

## Save

1. Click **Save**.

Hacado keeps you on the field page and confirms that your changes were saved.

### Good to know

Changing a field updates every service and add-on that already uses it. Review those attachments if the question or type changes in a big way.
