# Listing packages

The **Packages** list shows every prepaid package in your catalog. Use it to find a package, open one to edit, sell it to a customer, or delete it when it has no purchases.

Open **Appointments → Catalog → Packages**.

![Packages list](/img/catalog/packages/listing.png)

## Add a package

1. Click **Add New**.

See [Creating a new package](./creating-a-new-package).

## Search

1. Click the search box above the table.
2. Type part of the package name.

The list updates to matching rows. Clear the box when you want every package again.

## Row menu

1. Open the menu on a package row.
2. Choose **Update**, **Sell** (when the package is **Active**), or **Delete**.

- **Update** opens the package for editing. You can also click the package name.
- **Sell** opens the sell dialog. See [Selling a package](./selling-a-package).
- **Delete** asks you to confirm. Delete fails if the package already has purchases. See [Deleting a package](./deleting-a-package).

### Good to know

Saving a package does not put it on your public booking page by itself. Manage availability under [Services and packages](/docs/daily-use/appointment-settings-services-packages).
