# Overview

<PlanRequirement plan="Solo" />

**Packages** are prepaid session bundles tied to a [service](/docs/catalog/services). Each package has a name, short description, included **Sessions**, **Price**, optional validity and purchase limits, auto-confirm rules, and optional **Eligible staff**.

Open **Appointments → Catalog → Packages** in the side menu.

Creating a package does **not** show a booking-availability dialog. Clients only buy or redeem it on your booking page after you add it under **Settings → Appointments → Services and packages**. See [Services and packages](/docs/daily-use/appointment-settings-services-packages).

Sold copies of a package appear under [Sold packages](/docs/catalog/sold-packages).

## What you can do here

- [Listing packages](./packages/listing-packages) - search, open a row, sell, or delete when allowed.
- [Creating a new package](./packages/creating-a-new-package) - define the service, sessions, price, and staff.
- [Updating an existing package](./packages/updating-an-existing-package) - change details, limits, or eligible staff.
- [Selling a package](./packages/selling-a-package) - issue a package to a customer and collect payment.
- [Deleting a package](./packages/deleting-a-package) - remove a package that has never been sold.

### Good to know

Hacado blocks delete when the package already has purchases. Cancel or manage those under [Sold packages](/docs/catalog/sold-packages) instead of deleting the catalog definition.
