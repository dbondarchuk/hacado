# Selling a package

Sell a package when you issue prepaid sessions to a customer from the admin. The package must be **Active**. After a successful sale, the purchase appears under [Sold packages](/docs/catalog/sold-packages).

## Before you start

- The package already exists in Catalog. See [Creating a new package](./creating-a-new-package).
- The customer exists in your client list.
- For a **Payment link**, a payment app is installed and ready under **Apps**.

## Sell from the packages list

1. Open **Appointments → Catalog → Packages**.
2. Open the row menu on an **Active** package.
3. Click **Sell**.

You can also open **Sold packages** and use **Sell package** there when that control is available.

## Fill the sell dialog

![Sell package dialog](/img/catalog/packages/sell-dialog.png)

1. Confirm the **Package** (prefilled when you started from a row).
2. Pick the **Customer**.
3. Adjust **Price** if this sale differs from the catalog price.
4. Choose **Payment method**: **Cash**, **Card**, or **Payment link**.
5. For **Payment link**, pick the **App** if needed, set **Send via** (**Email**, **SMS**, or **Copy link**), choose **Destination** when sending, and confirm SMS consent if you send by text.
6. Confirm the sale.

Hacado issues the customer package and records payment (or a pending payment link). You are taken to the sold packages list filtered to that package.

### Good to know

**Sell** only appears for **Active** packages. Public online purchase still depends on listing the package under [Services and packages](/docs/daily-use/appointment-settings-services-packages).
