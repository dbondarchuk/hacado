# Working with sold packages

Use the row menu on a sold package to book visits, review history, correct used credits, or cancel and reactivate a customer’s purchase.

Open **Appointments → Catalog → Sold packages**, then open the menu on a row.

![Row menu actions](/img/catalog/sold-packages/row-menu.png)

## Schedule appointment

1. Click **Schedule appointment**.

This action appears only when the sold package is **Active** and still has remaining credits. Hacado opens a new appointment prefilled with the customer and package.

## View appointments

1. Click **View appointments**.

Hacado opens the appointments list filtered to bookings that used this sold package.

## View customer

1. Click **View customer**.

Hacado opens the customer’s packages area so you can see this purchase in their profile.

## Adjust used credits

Use this when the used count is wrong (for example after a manual correction).

1. Click **Adjust used credits**.
2. Set **Used credits** within the allowed range.
3. Optionally enter a **Reason**.
4. Save.

![Adjust used credits dialog](/img/catalog/sold-packages/adjust-credits.png)

**Adjust used credits** is not available for **Cancelled** packages.

## Cancel package

1. Click **Cancel package**.
2. Confirm in the dialog.

![Cancel package confirmation](/img/catalog/sold-packages/cancel-confirm.png)

Cancellation keeps remaining credits on the purchase so you can restore them later with reactivate.

## Reactivate package

1. On a **Cancelled** sold package, click **Reactivate package**.
2. Confirm in the dialog.

![Reactivate package](/img/catalog/sold-packages/reactivate.png)

Remaining credits stay as they are after reactivate.

### Good to know

Public package definitions and booking availability stay under [Packages](/docs/catalog/packages) and [Services and packages](/docs/daily-use/appointment-settings-services-packages). Sold package actions only change one customer’s purchase.
