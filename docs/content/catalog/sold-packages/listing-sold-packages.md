# Listing sold packages

The **Sold packages** list shows every package issued to a customer. Use it to find a purchase, open the row menu, or sell another package from Catalog.

Open **Appointments → Catalog → Sold packages**.

![Sold packages list](/img/catalog/sold-packages/listing.png)

## Search and filters

1. Click the search box above the table.
2. Type part of the package or customer name.
3. Optionally filter by **Package**, **Customer**, or status.
4. Click **Reset filters** when you want every sold package again.

Columns include the package name, customer, price, remaining and used credits, status, purchased date, and expiry when set.

## Sell another package

1. Use **Sell package** when that control is on the page.
2. Complete the sell dialog the same way as from the packages list.

See [Selling a package](/docs/catalog/packages/selling-a-package).

## Open actions

1. Open the menu on a sold package row.

![Row menu on a sold package](/img/catalog/sold-packages/row-menu.png)

Available actions depend on status and remaining credits. Full detail is in [Working with sold packages](./working-with-sold-packages).

### Good to know

After you sell from Catalog, Hacado often opens this list filtered to that package so you can confirm the new purchase.
