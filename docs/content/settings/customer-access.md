# Customer access

**Settings → Customer access** controls how customers receive the one-time code they use to sign in (for example in My account or when verification is required at booking).

Open **Settings** in the side menu, then **Customer access**. Or use the **Customer access** card on the [Settings hub](./settings).

![Customer access with Email on and Text message off](/img/daily-use/settings/customer-access.png)

## Email

1. Turn **Email** on to send the code to the customer’s email address.
2. Choose an **Email template** (required). This is the message that contains the code - for example **Customer OTP Email**.

At least one channel (email or phone) must stay on.

## Text message

1. Turn **Text message** on to send the code by SMS.
2. Text messaging must already be enabled under [Text messaging](./text-messaging). While texts are off, this option stays unavailable and sign-in uses email instead.
3. When phone is on, customers receive a built-in text with their code (or a custom template when your workspace allows it).

## Save

Click **Save** at the bottom after you change channels or the email template.
