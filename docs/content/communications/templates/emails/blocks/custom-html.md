# Custom HTML

**Custom HTML** is a block of HTML you write yourself. Drag it from **Layout**. Most emails do not need it. Use Heading, Text, and Button unless you need markup those blocks cannot make.

![Custom HTML selected in the email layout](/img/communications/email-block-custom-html-selected.png)

![Custom HTML field and the Open editor button](/img/communications/email-block-custom-html.png)

![HTML editor. Apply writes the markup back. Cancel closes it.](/img/communications/email-block-html-editor.png)

| Field           | What it changes                                                                           |
| --------------- | ----------------------------------------------------------------------------------------- |
| **HTML**        | The markup. It is required.                                                               |
| **Open editor** | Opens a larger HTML editor. **Apply** writes it back. **Cancel** closes without applying. |

HTML in email is easy to break in some inboxes. Prefer the other blocks when they can do the job.
