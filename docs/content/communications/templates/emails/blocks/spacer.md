# Spacer

**Spacer** is empty vertical space. Use it when a divider line would be too strong. Drag it from **Dividers** in the blocks panel.

![Spacer selected in the email layout](/img/communications/email-block-spacer-selected.png)

![Spacer height and background color](/img/communications/email-block-spacer.png)

| Field                | What it changes                                           |
| -------------------- | --------------------------------------------------------- |
| **Height**           | How tall the gap is. Must be greater than 0.              |
| **Background color** | Fill of the gap. Leave it clear to show the canvas color. |
