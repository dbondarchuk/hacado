# Email blocks

Drag a block from **Blocks** onto the canvas, then select it and use **Inspect**. Shared style controls (color, font, padding, alignment) are explained on the [Email builder](/docs/communications/templates/emails) page. The list below is only the fields that belong to that block.

| Block | Use it for |
| --- | --- |
| [Email layout](./blocks/email-layout) | The card around the whole email. It is always there. |
| [Heading](./blocks/heading) | A title. |
| [Text](./blocks/text) | A paragraph. |
| [Button](./blocks/button) | A link that looks like a button. |
| [Image](./blocks/image) | A picture. |
| [Avatar](./blocks/avatar) | A small profile image. |
| [Divider](./blocks/divider) | A horizontal line. |
| [Spacer](./blocks/spacer) | Empty vertical space. |
| [Container](./blocks/container) | A box that holds other blocks. |
| [Columns](./blocks/columns) | Two or three columns. |
| [Conditional](./blocks/conditional) | Show one set of blocks or another. |
| [Loop](./blocks/loop) | Repeat inner blocks for each item in a list. |
| [Custom HTML](./blocks/custom-html) | Your own HTML. |
| [Online meeting](./blocks/online-meeting) | Join details for a video visit. |
